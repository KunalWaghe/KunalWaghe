## 🌟 Featured Project

### 🇮🇳 Sahayak — AI-Powered Government Scheme Finder

*Helping citizens discover government schemes they qualify for — in their own language, by text or voice.*

[![Sahayak Repo](https://img.shields.io/badge/Repo-SAHAYAK__AI-6d28d9?style=for-the-badge&logo=github&logoColor=white)](https://github.com/KunalWaghe/SAHAYAK_AI)

</div>

- 🔍 Semantic search over **4,700+ scraped government schemes** using MuRIL embeddings + FAISS
- 🗣️ Multilingual Q&A and voice transcription powered by **Gemini 2.5 Flash**
- 🎨 Dark-themed Streamlit UI with gradient cards and an animated audio waveform
- 🏗️ Built solo, end-to-end, in a 1–2 week hackathon sprint
